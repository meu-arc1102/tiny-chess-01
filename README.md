A chess engine in under 4 KB of Python: a 0x88-board negamax alpha-beta search with quiescence, a transposition table and piece-square evaluation, playing the make.fun gauntlet through its env protocol under a fixed node budget, fully deterministically.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
